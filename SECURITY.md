# Security Policy

## Supported versions

Security fixes are currently targeted at the latest Lumen 1.0 release-candidate/stable line.

## Reporting a vulnerability

Please do **not** post suspected security vulnerabilities, access tokens, private server addresses or account information in a public GitHub issue.

Until a dedicated private security contact is published, use GitHub's private vulnerability reporting feature if it is enabled for this repository. If it is not yet enabled, avoid posting sensitive details publicly and open a minimal issue asking for a private contact method.

When reporting a vulnerability, include:

- affected Lumen version
- Windows version
- Jellyfin server version when relevant
- reproduction steps
- expected and actual behaviour
- impact assessment

Never include a live Jellyfin access token or password.
