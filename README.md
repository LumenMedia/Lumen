# Lumen

**Lumen** is a native Windows desktop client for Jellyfin, built with WinUI 3 and .NET.

Lumen is designed to feel like a first-class Windows media app rather than a web wrapper. The interface, playback stack, downloads, music experience, settings and offline behaviour are implemented natively.

> **Status:** Lumen 1.0.0 RC1. This is a release candidate and may still contain bugs.

## Highlights

- Native WinUI 3 interface with Lumen's dark plum/purple visual language
- Jellyfin server discovery, sign-in and remembered sessions
- Home experience with Featured, Continue Watching, Up Next, recently released and recently added media
- Separate Movie, TV and Kids library presentation
- Native movie and episode playback with resume support
- Automatic Direct Play / Direct Stream / Transcode negotiation
- Audio-track and subtitle selection
- Plex-style 10-second back / 30-second forward controls
- Intro and credits handling, including Up Next playback flow
- Offline downloads with pause, resume, retry, quality choices and local playback
- Music home, artists, albums, songs, playlists, genres and favourites
- Persistent music mini-player and queue
- Synced lyrics through LRCLIB plus local Lyrics AutoSync using Whisper
- Server, playback, subtitles, music, downloads, desktop and advanced settings
- Offline startup when a server is unavailable but downloaded media exists

## Requirements

- Windows 10 version 2004 / build 19041 or newer
- x64 Windows is the primary release target
- A reachable Jellyfin server for online library and streaming features

For source builds you will also need:

- Visual Studio with .NET desktop development / Windows App SDK tooling
- .NET 10 SDK
- Microsoft Visual Studio Installer Projects extension if you want to build the MSI installer

## Building from source

1. Clone the repository.
2. Open `Lumen.sln` in Visual Studio.
3. Select `Release` and `x64`.
4. Restore NuGet packages if Visual Studio has not already done so.
5. Build the `Lumen` project.

Lumen is self-contained and uses the Windows App SDK self-contained deployment model.

### Required assets

The following files are part of Lumen's application identity/runtime and are expected in source control:

```text
Assets/
  Lumen.ico
  LumenLogo.png
  LoginBackground.png
  AutoSync/
    ggml-tiny.bin
```

`ggml-tiny.bin` is used by the local lyrics AutoSync feature.

## Building the MSI installer

The setup project is in `Lumen.Setup` and uses **Microsoft Visual Studio Installer Projects**.

1. Install the Microsoft Visual Studio Installer Projects extension.
2. Open `Lumen.sln`.
3. Select `Release` / `x64`.
4. Rebuild `Lumen.Setup`.
5. The resulting MSI is written under `Lumen.Setup/Release`.

The setup project's post-build tooling applies Lumen branding, repairs nested publish directories generated by Visual Studio Installer Projects, configures optional Start Menu/Desktop shortcuts and sets the Installed Apps icon.

## Project structure

```text
Assets/           Branding and local AutoSync model
Controls/         Custom WinUI controls/helpers
Converters/       XAML converters
Models/           Jellyfin and navigation models
Services/         Jellyfin API, downloads, playback helpers, lyrics and settings
ViewModels/       MVVM view models
Views/            WinUI pages
Lumen.Setup/      Visual Studio MSI project and post-build tooling
```

## Security and privacy

Lumen connects directly to the Jellyfin server configured by the user. Remembered Jellyfin access tokens are protected using Windows DPAPI rather than stored as plain text.

Please do not report security vulnerabilities in a public issue. See [SECURITY.md](SECURITY.md).
